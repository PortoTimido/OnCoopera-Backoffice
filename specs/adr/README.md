# Architecture Decision Records

ADRs registram decisões transversais e suas consequências. Estados permitidos: `Proposto`, `Aceito`, `Substituído` e `Rejeitado`.

Uma decisão aceita pode ser alterada apenas por novo ADR que a substitua. O novo documento deve apontar para o anterior; o anterior deve ser atualizado com o link de substituição.
