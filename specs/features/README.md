# Feature specifications

Cada subdiretório representa uma funcionalidade aprovada ou em elaboração e deve seguir o fluxo e os templates descritos em [`specs/README.md`](../README.md).

Não use este diretório para ideias soltas. Uma nova feature deve começar por `requirements.md`, declarar pendências bloqueantes e avançar para design somente quando o comportamento esperado estiver suficientemente claro.
